# Projects

A **project** groups chats and gives the AI things to work from.

## What a project holds

- **Instructions** sent with every chat in the project (up to 4,000 characters).
- **Files**: PDF, Word, PowerPoint, email, text and pictures. Drop them on the project's page or use **Add files**. Lumen reads them on your computer and keeps the text encrypted in your profile.
- **Pages**: in any chat, the + menu has **Add this tab to the project**, and a tab's right-click menu has **Add to project**. The page is pinned by address and title.
- **Memory**: when Memory is on, notes the AI saves in a project chat belong to that project only. They show on the project's page, where you can forget them.
- **Defaults**: a model for new chats, plan-first, and switches for connectors and MCP tools.

## How the AI uses them

Every chat in the project gets a short list of the files and pages. The AI reads one, or searches them all, with the project_files tool. Only then does that text go to your AI provider. Plan mode allows the tool.

## Deleting

Deleting a project shows **Undo** for a short while. After that its files and memory are erased.

## Not included

There is no lumen://projects address (the page opens inside the chat page), and files can't yet be dragged in from outside by path.
